# Prompt Shield

Prompt-injection defense for LLM apps — sanitize inputs, detect jailbreak patterns and harden system prompts before production. Part of the Zion Tech Group App Network.

**Live app:** https://ziontechgroup.com/prompt-shield/

## About
Prompt Shield is a free, browser-based tool from the [Zion App Network](https://ziontechgroup.com/apps/) (700+ open-source AI & IT ops apps). Category: **Security & LLM Tools**.

## Features
- Real-time prompt-injection & jailbreak detection
- Input sanitization with configurable policy rules
- System-prompt hardening recommendations
- Risk scoring per request with exportable reports
